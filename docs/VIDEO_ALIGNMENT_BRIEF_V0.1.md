# 《带上她的眼睛》动画脚本创作简报 v0.1

状态：首轮脚本试写依据，不是已批准制作稿。用户要求拉子任务先出脚本，动画气质参考皮克斯，以小王子和玫瑰的故事表达。

## 核心判断

故事表达“你留在家里，也可以和我一起看见世界；我分享时，也能得到你的回应”。一段温暖、略带幽默和克制留白的冒险，具体动作胜过概念旁白。

## 暂定制作边界

- 目的：用于产品创意讨论，让观众理解分享与回应的关系。受众暂定初次接触产品的人；Kim 审稿。
- 时长暂定 60 秒、中文、16:9；本轮只出 Markdown 脚本与镜头表，不生成视频、配音或素材。
- 视觉：皮克斯式温暖 3D 动画，清楚的角色表演、材质与光线。小王子与玫瑰作为叙事角色，不逐句复述原著、不使用现成电影片段。后半段通过视觉转场对应到用户与 Reachy Mini。
- 角色对白为主、旁白少量；同期字幕；轻柔原创配乐方向，风声与按键声推动叙事，暂无选定音乐/声音资源。
- 不做功能清单和夸大营销。产品段落是概念演绎，不能包装成已完成真机演示。

## 镜头方向

1. 出发前：小王子准备远行，玫瑰扎根在星球上，关系由一个具体照顾动作建立。
2. 路上：他遇见值得分享的小事，意识到她看不见。
3. 转折：看见月亮，主动把视野分享给她；用画面与动作交代分享意图。
4. 回应：她看见，并给出属于这个瞬间的短回应；双向关系成立，不只是远程摄像头。
5. 产品对应：眼镜腿手动按键拍照 → 家中 Reachy Mini 的同一角色 → M5 小表情/短句回应。手机只提供热点，不出现在操作流程。
6. 收尾：两端共享同一轮月亮或呼应开头的动作，片名《带上她的眼睛》。结尾句由脚本子任务创作，不预设硬广 CTA。

## 产品事实与审稿风险

- 家中实体 Reachy Mini。眼镜无 3D 投影、无麦克风；拍摄必须手按眼镜腿按键，不眨眼拍、不语音唤醒、不拿 M5 拍。
- 随身 M5StickS3 展示同一角色的短表情与短句，语音可听已有其他任务现场确认，但新照片回应链路尚未实现。
- 震动为用户优先偏好，需外接模块验证；脚本可以列为条件替代镜头，不作为现有板载能力演出。
- 不表现心情数值、疲惫、陪读、暂停、养成和游戏。
- 不把分享变成“离开她会内疚”或要求主人持续照顾；玫瑰有自己的回应，不只是被动等待。
- 对应关系要清楚，不能让观众误以为产品能投影玫瑰、让机器人穿越或持续直播。
- 每句对白要有对应画面；时间总和可执行，给按键、接收和回应留出可辨认的动作时间。

## 素材与开放项

本轮不读私人照片、不复制 forbetter 私人内容。参考 PRD 的低压力、具体、有真实依据的表达。片幅、渠道、角色造型、镜头比例和配音人选都未定，试稿不冻结这些选择。
