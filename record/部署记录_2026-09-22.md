## 三、下一步行动

### 1. 接入 Luma 眼镜

- [ ] 唤醒眼镜，关闭手机端占用连接的应用。
- [ ] 执行：

```powershell
Set-Location E:\EVO_Hack\upstream\luma-core
.\target\release\examples\luma.exe scan
.\target\release\examples\luma.exe info
.\target\release\examples\luma.exe photo --ai look.jpg
```

- [ ] 确认 `look.jpg` 是新拍摄图片，再配置 `LUMA_CLI_PATH` 使用桥接服务。

### 2. 接入 Reachy

- [ ] Lite：连接 USB 并启动 Daemon；Wireless：确认机器人实际 IP。
- [ ] 验证：`http://<Reachy-IP>:8000/api/daemon/status`。
- [ ] 验证：`http://<Reachy-IP>:8000/openapi.json`。
- [ ] 执行小幅触角动作，确认动作完成而非仅 HTTP 200。
- [ ] 播放已知 WAV，确认声音来自 Reachy 扬声器。

### 3. 接入视觉模型

- [ ] 配置 `MODEL_BASE_URL`、`MODEL_API_KEY`、`VISION_MODEL`。
- [ ] 先上传明显特征的本地图片，确认答案确实与图片相关。
- [ ] 再接入 Luma 图片，验证 `image_id`、图片内容和回答对应。

### 4. 完成联调与安全配置

- [ ] 使用随机 `BRIDGE_TOKEN`，不要继续使用本地默认 token。
- [ ] 如需手机访问，将 `BRIDGE_HOST` 改为 `0.0.0.0`，仅开放可信局域网端口 `8088`。
- [ ] 完成指南中的 T01-T12：纯文字、上传图片、拍照、追问、重试、超时、离线、取消、手机访问和 20 轮稳定性。
- [ ] 记录眼镜型号/固件、Reachy 类型/IP、模型名、音频结果及各阶段耗时。

## 四、启动方式

```powershell
Set-Location E:\EVO_Hack
$env:BRIDGE_TOKEN = 'replace-with-a-random-local-token'
.\run_bridge.ps1
```

浏览器访问 `http://127.0.0.1:8088/`。停止服务：前台运行按 `Ctrl+C`；后台运行时使用 `Stop-Process -Id <PID>`。
